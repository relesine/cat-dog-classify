## 3. GitHub 发布

### 3.1 仓库设置

- 仓库名称建议：`mobilenetv2-dogs-vs-cats` 或 `dogs-vs-cats-mobilenetv2`
- 仓库描述建议：`基于 MobileNetV2 迁移学习的猫狗图像二分类，针对 CPU 环境优化，5 轮训练约 13 秒`
- Topics 建议：`deep-learning`、`tensorflow`、`mobilenetv2`、`transfer-learning`、`image-classification`、`dogs-vs-cats`

### 3.2 文件放置

```text
仓库根目录/
├── README.md
├── dogs-vs-cats.py
└── docs/
    ├── 项目说明文档.md
    ├── PUBLISH.md
    └── images/
```

`README.md` 中的图片使用相对路径 `docs/images/...`，上传后可直接渲染。

### 3.3 注意事项

1. README 使用标准 Markdown，未使用 HTML 标签，GitHub 可完整渲染；
2. 不依赖 Mermaid，避免不同平台渲染差异；
3. PDF 与 PNG 文件均小于 GitHub 单文件 100 MB 限制，无需 Git LFS；
4. 建议在仓库右侧 About 区域填写描述与 Topics，便于检索；
5. 如需添加开源协议，请根据实际意愿选择，当前文档未声明具体许可证。

## 4. Gitee 发布

### 4.1 发布方式

- 新建仓库后直接上传文件，或从 GitHub 导入仓库；
- 保持与 GitHub 相同的目录结构；
- README 与图片相对路径可直接复用。

### 4.2 注意事项

1. Gitee 对 HTML 标签和部分扩展语法支持不如 GitHub，本文档已避免使用；
2. Gitee 图片首次加载可能较慢，属于平台缓存机制，刷新即可；
3. 若仓库设置为公开，请确认 PDF 中不包含个人敏感信息；
4. Gitee 的 Markdown 目录锚点对中文标题支持良好，可保留目录；
5. 数据集与 `.venv/` 同样不要上传。

## 7. 常见发布问题

### 图片在 GitHub 显示但 Gitee 不显示

确认图片路径大小写与文件名完全一致，并检查是否已成功推送 `docs/images/` 目录。Gitee 对中文文件名支持良好，但建议保持当前 ASCII 文件名。

### CSDN 粘贴后图片全部失效

这是正常现象。CSDN 不会读取仓库内的相对路径，需要在编辑器中使用“图片”按钮逐张上传，并替换链接。

### CSDN 目录锚点跳转异常

CSDN 对部分中文锚点的支持存在差异。若目录跳转失败，可删除目录，或在 CSDN 编辑器中使用其自带的“目录”组件。

### 仓库体积过大

检查是否误提交了 `.venv/` 或数据集。`.venv/` 约 1.6 GB，数据集更大，均不应进入仓库。
